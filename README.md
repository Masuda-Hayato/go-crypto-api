# 📈 仮想通貨リアルタイム監視・API配信システム

外部APIから暗号資産の価格を定期取得してデータベースに永続化しつつ、異常な価格変動を検知するバックエンドシステムです。収集したデータはWebダッシュボードおよびJSON APIとして配信されます。

## 🛠 技術スタック
* **言語:** Go (Golang)
* **データベース:** SQLite3
* **外部API:** CoinGecko API
* **標準ライブラリ:** `net/http`, `database/sql`, `encoding/json`, `text/template`

## ✨ 主な機能とアーキテクチャ

1. **自律型データ収集バッチ (`main.go`)**
   * `time.Ticker` を用いた1分ごとの非同期定期実行フェッチ
   * JSONデータの構造体（Struct）へのマッピング
   * `database/sql` を用いたSQLiteへの安全なデータ永続化
2. **ポインタを活用した異常検知ロジック**
   * ポインタ (`*float64`) を用いて前回の価格状態をメモリ上に保持
   * 1分間で設定した閾値（例: 5,000円）以上の変動があった場合にアラートを出力
3. **Webサーバー＆REST API (`server.go`)**
   * Goの標準ライブラリのみで構築した軽量Webサーバー
   * `html/template` を用いた直近30件の価格推移ダッシュボード（UI）
   * 他のアプリケーションから利用可能なJSON APIエンドポイント（`/api/prices`）の提供
